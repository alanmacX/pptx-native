EFFECT 01 / PHOTO GALLERY
照片横向滑动的画廊
四张 native picture 在同一轨道里横向滑动；左右用原生形状做遮罩，效果像 carousel，不是视频。
图片来源：Wikimedia Commons，本地下载后裁切为 PPT native picture；动画为 animMotion + animEffect + animScale。
EFFECT 02 / CURVED TIMELINE
弯曲曲线的时间线延展
曲线拆成多个 SVG line native connector，按路径顺序 staggered wipe。节点在曲线经过时弹出。
概念出现
路径加速
证据汇合
阶段跃迁
曲线不是一张图：每段都是 PowerPoint connector，延展感来自分段 wipe + 节点 compose。
EFFECT 03 / WIPER ERASE
雨刮器擦掉图片
底层是 clean photo，顶层是 rainy photo。顶层做 exit-wipe，雨刮片同步横扫，形成“擦掉”的感觉。
实现方式：clean 底图 + 9 个 rainy picture slices 错峰 exit-wipe，刮片用 native motionPath 同步扫过。
